# pet-claude 0.1.0-beta.1

Première beta publique de pet-claude : un compagnon 3D sur le bureau macOS qui réagit à Claude Code.

**Fichier** : `pet-claude-0.1.0-beta.1.pkg` (2,7 Mo, Apple Silicon)
**SHA-256** : `a8ed959299f0819245e8815b1afaf5de60e8c975b2b95fae74f38435f6c328ae`

## Nouveautés
- Pet en volume 3D (CSS 3D) : regard et orientation qui suivent le curseur, clignements, sommeil, panique quand on le prend, lancer avec rebonds.
- Animations par outil : lunettes (lecture), clavier (Bash), marteau et enclume (modifications), jumelles (web). Confettis après un gros travail.
- Sons synthétisés (voix, frappe, impacts), réglables.
- Plusieurs sessions Claude Code reconnues, avec pastille de projet sur les bulles.
- Mini-chat (double-clic) : question posée dans une copie de la session choisie, en lecture seule, réponse en streaming.
- Fenêtre de réglages (`/settings`) : comportement, sons, système. Icône Dock uniquement pendant les réglages.
- Installateur macOS avec choix des options.
- Au-dessus des apps en plein écran, sur tous les espaces, multi-écrans.

## Installation
Clic droit sur le `.pkg`, Ouvrir (non signé par un compte développeur Apple). Détails dans le README.

## Limites connues
Voir « Limites connues (beta) » du README. Principales : Apple Silicon seulement, app non notarisée, scripts de
post-installation non testés en conditions réelles avant publication, accessoires positionnés à l'œil.

## Pour les testeurs
Merci de signaler : tout ce qui est coupé ou mal placé (accessoires, bulle), les pets en double ou qui clignotent sur plusieurs écrans,
un clavier qui ne répond pas dans le mini-chat, et `/tmp/pet-claude-install.log` en cas d'échec de l'installation.
