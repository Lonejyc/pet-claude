# pet-claude 1.0.0

Première version stable. Le détail des fonctionnalités est dans le [README](../../README.md).

**Fichier** : `pet-claude-1.0.0.dmg` (Apple Silicon)
**SHA-256** : `3d5397548fb8c8c441a3449e406044023b8aa30cbe02c44588787198ce2c8462`

## Nouveau depuis la beta 7
- **Installation par .dmg** : ouvre l'image, glisse `pet-claude.app` sur Applications, lance-la. À la toute première ouverture, l'app active seule les hooks Claude Code et le lancement
  au démarrage (comme l'ancien .pkg avec ses cases cochées). Rien n'est refait ensuite : tout se change dans les Réglages. Si l'app tourne depuis le .dmg lui-même, ou si une
  configuration existe déjà (mise à jour d'une beta), elle ne touche à rien.
- **Noël** : bonnet de Noël et bois de renne dans les accessoires, grelots à la fin d'une tâche, boîte à musique à l'endormissement. Une case dans Réglages > Fêtes ;
  tant qu'on n'y touche pas, c'est actif en décembre seulement.
- **Nouvelle icône** : le pet orange avec son bonnet de Noël, sur un fond graphite plus sobre.

## Installation
Ouvre le `.dmg`, glisse l'app sur Applications, puis clic droit sur l'app, Ouvrir la première fois (non signée par un compte développeur Apple).
Tu peux installer par-dessus une beta : tes réglages, tes hooks et ton lancement au démarrage sont conservés.
Le `.pkg` n'est plus fourni (`installer/build-pkg.sh` reste dans le dépôt).

## Limites connues
- La première ouverture automatique (hooks et lancement au démarrage) est couverte par des tests, **pas encore essayée à la main** depuis un vrai glisser-déposer.
- Apple Silicon seulement, app non notarisée.
