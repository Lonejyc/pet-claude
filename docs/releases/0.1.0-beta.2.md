# pet-claude 0.1.0-beta.2

**Fichier** : `pet-claude-0.1.0-beta.2.pkg` (2,8 Mo, Apple Silicon)
**SHA-256** : `a22b7b2c824f535844b5e1814e4ff7c6f2cf37b103f11c9d63d0728278c48cf2`

## Nouveautés depuis la beta 1
- **Icône dans la barre de menus**, toujours présente : silhouette 2D noir et blanc du pet (image « template » macOS,
  blanche en mode sombre), avec un menu **Réglages…** et **Quitter**. Il n'y avait avant aucun moyen visible de
  fermer le pet ou d'ouvrir les réglages (hors commandes `/settings` et `/quit` du champ de saisie).
- Retrait du plugin « opener » hérité du modèle Tauri, inutilisé : une permission en moins.
- README : direction artistique et planche des états du pet.

## Installation
Clic droit sur le `.pkg`, Ouvrir (non signé par un compte développeur Apple). Si tu as la beta 1, installe par-dessus :
l'installateur remplace l'app. Détails dans le README.

## Limites connues
Inchangées depuis la beta 1 (voir le README) : Apple Silicon seulement, app non notarisée, scripts de
post-installation non testés en conditions réelles avant publication, accessoires positionnés à l'œil
(la scène du marteau, vue de face, est la moins lisible).
