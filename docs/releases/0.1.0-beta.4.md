# pet-claude 0.1.0-beta.4

**Fichier** : `pet-claude-0.1.0-beta.4.pkg` (2,8 Mo, Apple Silicon)
**SHA-256** : `81d3b26cdbcdfdf905a5a80fec418db2df6e6981bef58ceb2fdcd34b55a37607`

## Correctifs
- **Sons rétablis après la veille du Mac** : WebKit laissait le contexte audio muet au réveil, le pet en recrée un.
- **Arêtes du pet sans liserés** : plus de fines lignes claires sur les bords du pavé quand il tourne.
- **Mini-chat sans session** : sans session Claude Code ouverte, le pet répond aux questions générales sans accès aux
  fichiers, et renvoie vers un terminal pour les questions sur du code. Le chat l'indique à la place des étiquettes de session.

## Installation
Clic droit sur le `.pkg`, Ouvrir (non signé par un compte développeur Apple). Tu peux installer par-dessus une beta précédente.
Si tu viens de la beta 1 ou 2, lis les notes de la beta 3. Détails dans le README.

## Limites connues
Apple Silicon seulement, app non notarisée, scripts de post-installation (root) non testés en conditions réelles avant
publication, accessoires positionnés à l'œil. La consommation au repos n'a pas été mesurée.
