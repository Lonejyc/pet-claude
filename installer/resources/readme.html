Ce qui sera installé ou modifié

  • pet-claude est copié dans /Applications. Rien d'autre n'est écrit en dehors de ton dossier personnel.
  • Connecter Claude Code (recommandé) ajoute cinq hooks dans ~/.claude/settings.json, à côté des tiens. Une sauvegarde est faite dans settings.json.bak-pet-claude. Sans eux, le pet ne voit aucune session.
  • Lancer au démarrage crée un agent de lancement dans ~/Library/LaunchAgents.
  • Personnalité « Pet » (optionnel) ajoute une ligne 🟧 en tête de chaque réponse de toutes tes sessions Claude. Décoché par défaut.

Tout est réversible depuis la fenêtre de réglages du pet.
