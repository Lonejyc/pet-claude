pet-claude est installé

Le pet apparaît sur ton bureau. Quelques gestes :

  • Double-clic sur le pet : lui poser une question (la session visée est choisie par les pastilles, Tab pour en changer).
  • Glisser : le déplacer ; lâcher en mouvement : le lancer.
  • Icône du pet dans la barre de menus (en haut à droite) : Réglages… et Quitter. Au clavier : /settings et /quit dans le champ de saisie.

Les sessions Claude Code déjà ouvertes doivent être relancées pour que le pet les voie.
